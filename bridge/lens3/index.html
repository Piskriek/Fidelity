Reading the page

  • Surprise is how unexpected the answer was, above its usual: 0 is usual, below 0 is less unexpected than usual. Not good or bad, so it has one plain colour. field sting[0], the recorder's name: −ln(pAnswer) − its running mean (keep 15/16)
  • Fit (not fitness) is how close its guess is to what a fruit really does now. The world's class picks which guess is drawn; the being cannot see that class. Up means it fits the world better, not that it is better. It also reads its own energy and health, so a trail can move while the world stays the same. No non-learning comparison is drawn, so a climb here is one life's, not proof that beings learn.
  • Gold burst: its guess for a fruit that changed class passes half for the first time this season. Celebrating that crossing, and rooting for the beings, are the project owner's asks. The half line is the owner's value choice (default until ruled). It never grades anyone, and crossings in different valleys are not a race: each valley and fruit differs.
  • Not sensed tiles hold no number. The value sits in the world band right under each one.
  • Pain: no felt-pain channel exists and none is drawn. The answers it gets back (fed, poisoned, fainted, the starving flag) are words for events it is told about, not feelings. Why it went down, and the engine's numbers (gain, cost, V), are the world's. Felt pain is a higher-self choice, never a setting (the project owner's ruling).
  • Intensity is a world number that only goes down (2, then 1 after a loop-break). The weights stay as set at intensity 2.
